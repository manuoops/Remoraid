## Manual de Utilização

- 1- No Google Colab é onde será feito o tratamento do nosso banco de dados para que suas informações fiquem sem erros e limpas.

- 1.1- Aperte no botão de Play no canto superior esquerdo da tela

  ![](docs/img/manuais/utilizacao01.png)

- 1.2- Um Pop-up irá aparecer clique em “Executar assim mesmo”

  ![](docs/img/manuais/utilizacao02.png)

- 1.3- Agora espere alguns segundo que o Colab ira se conectar e executar o código

- 1.4- Após conectado e o código executado, vá até o final da página e você encontrara onde será selecionado o Banco de Dados, clique em “Escolher Ficheiros”

  ![](docs/img/manuais/utilizacao03.png)
  
- 1.4.1- Escolha o arquivo das Bombas

  ![](docs/img/manuais/utilizacao04.png)

- 1.4.2- Espere até todo o arquivo estar carregado e pronto ele será baixado automaticamente em seu computador

  ![](docs/img/manuais/utilizacao05.png)
  
- 1.5- Agora com o arquivo tratado em mãos e o Diretório do GitHub baixado (Link fornecido no manual de instalação) abra o VsCode e em seguida a pasta onde esta o diretório baixado

  ![](docs/img/manuais/utilizacao06.png)

- 1.5.1- Logo após isso pegue o arquivo das Bombas baixado pelo Google Colab e o arraste e coloque na partição “public”

  ![](docs/img/manuais/utilizacao07.png)
  
- 1.6- Após isso inicie um novo terminal, apenas clique no botão “Terminal” no canto superior esquerdo da tela

  ![](docs/img/manuais/utilizacao08.png)
  
- 1.6.1- Após isso será necessário utilizar dois comandos:

## 1° npm install
  ![](docs/img/manuais/utilizacao09.png)

## 2° npm run dev
  ![](docs/img/manuais/utilizacao10.png)

- 1.6.2- Após a utilização dos comandos para abrir o site basta segurar Ctrl e clicar com o botão esquerdo do mouse onde está o link http://localhost:5173/ ou apenas copiá-lo e colá-lo no google na barra de pesquisa [URL 🔗](http://localhost:5173/)
